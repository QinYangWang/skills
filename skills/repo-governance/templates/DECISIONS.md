## How to add one

1. It changed how the code is written, not just what one function returns.
2. Name who decided it and when. If you cannot, it is not a decision.
3. State what it forbids — that is the half a reviewer uses.
4. Add the review row it justifies to [`REVIEW.md`](REVIEW.md), or say why none
   is needed.

A decision with no review row is a story. A review row with no decision or
postmortem is an opinion.
